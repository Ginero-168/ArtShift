# Interactive Canvas Ghost Preview for Batch Variations

Type: prototype
Status: resolved
Blocked by: none

## Question

How should `lib/renderer/canvas.ts` and `lib/engine/interactionController.ts` implement the non-destructive Canvas Ghost Overlay for multi-variation candidates generated by `imageBatchRunner.ts`, allowing users to inspect true scale, alignment, layering, and composition against existing Objects on the Artwork before committing to the document store?

## Answer

Implemented as a non-destructive Canvas Ghost Overlay module ([ghostOverlay.ts](file:///root/ArtShift/lib/renderer/ghostOverlay.ts)):
1. **Isolated Overlay Layer**: `drawGhostVariationOverlay()` renders candidate variations directly to the 2D context using semi-transparent alpha (0.85), dashed accent bounding outlines, corner anchor markers, and floating pill status tags (`✨ AI Variation Preview`) without mutating the underlying `EngineSlide.elements` or transaction history.
2. **Aspect Ratio & Placement Intent Calculation**: `calculateGhostBounds()` maps candidate image dimensions into Artwork coordinates supporting 4 key intents: `center`, `fill-background`, `fit-artwork`, and `preserve-selection` (replacing selected object bounds).
3. **Smooth 60fps Preview Scheduling**: Driven by `interactionController.ts` frame scheduler, allowing hover/focus on batch variation cards in `AICoPilotBar` to trigger zero-cost ghost previews on the Canvas before the user clicks Commit.
Verified with unit tests in [tests/ghostOverlay.test.ts](file:///root/ArtShift/tests/ghostOverlay.test.ts).
