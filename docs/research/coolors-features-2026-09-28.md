# Coolors — ฟังก์ชันและแนวคิดสำหรับ ArtShift

ตรวจวันที่ 2026-09-28 จากเว็บไซต์ Coolors และ Help Center ทางการ สถานะ: งานศึกษา ไม่ได้แก้แอป ArtShift

## วิธีตรวจและขอบเขต

เปิดหน้า Home, Generator, Image Recolor และ Pricing ผ่าน browser จริงโดยไม่ล็อกอิน ทดลองกด Space ใน Generator พบว่าพาเลตต์และ URL เปลี่ยน อ่านเมนูและรายละเอียดราคาโดยตรง ส่วนฟังก์ชันสมาชิก/Pro อ้างอิงรายการของผู้ให้บริการ ยังไม่ได้ทดลองชำระเงิน ใช้งาน AI หรือ export ทุกชนิด

Help Center บางบทความลงวันที่ 2019 จึงใช้ประกอบกลไกการใช้งาน และใช้หน้า Pricing ปัจจุบันสำหรับข้อจำกัดแพ็กเกจ หลีกเลี่ยงอ้างโดเมนคล้ายกันที่ยังไม่ยืนยัน

## ข้อสังเกตเรื่อง Recolor และ Vectorize

หน้าเว็บบางรายการที่ถูก index ใช้ชื่อ SVG Recolor แต่หน้าปัจจุบันที่เปิดจริงชื่อ Image Recolor จึงไม่สรุปว่าเป็น SVG-only โดยยังไม่ได้ทดลองนำเข้าไฟล์ และไม่ใช้ input file ของ modal ส่วนกลางเป็นหลักฐานตัดสินชนิดไฟล์ของเครื่องมือทั้งหมด

สิ่งที่ยืนยันคือ workflow เปลี่ยนสีและบันทึก variants ไม่พบหลักฐานในหน้าที่ตรวจว่ามี raster-to-vector tracing, node/Bézier editing หรือระบบซ่อม topology ดังนั้นประโยชน์ต่อ ArtShift คือการจัดการสีและ preview หลัง vectorize ไม่ใช่ใช้แทนเอนจิน vectorize

## ข้อเสนอสำหรับ ArtShift — ความเห็นจากการศึกษา

1. **Global palette + brand locks:** ล็อกสีแบรนด์แล้วสร้างสีประกอบใหม่ และใช้สีอ้างอิงร่วมกันกับ Objects หลายชิ้น
2. **Palette extraction:** ดึงสีจาก Image ที่เลือกเพื่อใช้กับ Artwork หรือ constrain ผล vectorize
3. **Recolor preview:** ลองสีบน Artwork จริง แยกบทบาท Background/Text/Accent โดยตรวจ contrast ไม่สุ่มสลับทุกสีแบบไม่มีบริบท
4. **Variants:** สร้าง A/B/C เฉพาะสีโดยไม่เปลี่ยน geometry และ commit เป็นหนึ่ง undo step
5. **Accessibility checks:** ตรวจคู่ข้อความ/พื้นหลังจริงและจำลองการมองเห็นสี; การตรวจพาเลตต์อย่างเดียวไม่ครอบคลุม gradients/ภาพพื้นหลังทั้งหมด
6. **Libraries and export:** เก็บพาเลตต์ระดับ project และส่งออก SVG/CSS tokens ตามการใช้งานจริง

ลำดับเริ่มที่เหมาะ: Extract → Lock → Recolor → Preview → Apply แล้วจึงเพิ่ม AI และคลังสาธารณะภายหลัง จุดเด่นที่ ArtShift ทำได้คือใช้พาเลตต์กับ Artwork และผล vectorize ที่แก้ไขอยู่โดยตรง
